# My Travel Website

A simple, static travel website built with pure HTML to showcase different destinations, travel essentials, and package options. This project demonstrates the use of basic HTML tags for structuring content, formatting text, and embedding media.

## 🚀 Live Demo

You can view the live website here: [assignment1.html](assignment1.html) (if hosted) or simply by opening the `index.html` file in your browser.

## ✨ Features
*   **Vibrant Content:** Engaging paragraphs discussing the pros and cons of modern travel.
*   **Visual Appeal:** Includes image collages and embedded YouTube videos to create an immersive experience.
*   **Travel Essentials:** Organized lists for packing items, top destinations, and a glossary of travel terms.
*   **Pricing Table:** A clear and simple table outlining different travel packages with prices and durations.
*   **Hyperlinks:** Easy navigation with both internal and external links, including a link to Google Travel.

## 💻 Technologies Used
This project is built using the following technologies:
*   **HTML5:** For the entire structure and content of the webpage.
*   **YouTube API (via `<iframe>`):** To embed videos and enhance the multimedia experience.
*   **External Image Hosting:** Uses publicly available image URLs to display pictures on the site.
